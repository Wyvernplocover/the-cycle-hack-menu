## 🧩 About

**The Cycle Frontier Companion** is a curated list of The Cycle Frontier open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot tracker, map notes
- **Quality-of-Life Helpers** — inventory catalog, loadout notes, overlay notes
- **Research Notes** — raid layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Loot Tracker — mark containers and resources while exploring
- Map Notes — annotate drop zones and extraction points
- Replay Notes — record and review raid runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse weapons, armor, materials, consumables
- Custom Loadout Notes — organize gear presets
- Visibility Notes — improve contrast for loot on the ground

### Aimbot
- Training Notes — segment study on any map layout
- Stamina Control Notes — manual stamina tuning in practice
- Jump Buffer Notes — chain complex maneuvers in the editor
